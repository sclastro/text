全形／半形轉換

轉換全形（Ａ１）與半形（A1）字元。

標點格式化

統一引號樣式、修正省略號與破折號、清理標點前後空白。

移除多餘空白、空行、零寬字元，統一換行符。

拼音／粵拼

繁簡轉換

繁體（台灣／香港）與簡體中文互相轉換，使用 OpenCC 詞彙級轉換。

Markdown 預覽

即時預覽 Markdown，並可匯出 PDF 或複製 HTML。

CSV 表格

將 CSV 文字或檔案解析成表格，並可複製為 Markdown 表格。

JSON 格式化

格式化、壓縮、驗證 JSON。

中文數字

阿拉伯數字、中文數字、財務大寫互相轉換。

QR Code 生成

由任意文字或網址生成二維碼，可下載 PNG。

時區轉換

將一個時刻換算成多個時區，並顯示星期。

單位換算

長度、重量、溫度、面積換算，包括港式單位（斤、両、呎）。

短網址還原

嘗試將短網址還原成完整 URL。

⚠️ 純前端受瀏覽器 CORS 限制，部分短網址服務無法直接讀取。可選用公開 CORS 代理（需自行承擔風險）。

抽獎轉盤

輸入學號範圍，按轉盤中央的「抽」（或空白鍵），轉盤停下時指針所指的學號即為抽中者。

農曆／公曆換算

公曆與農曆互相換算，顯示星期、生肖、干支、節氣。

倉頡／速成查詢

輸入中文字，顯示每個字的倉頡碼組合（及速成碼）。

檔案格式偵測

不知道檔案屬何種格式？將檔案拖放到此處，即可讀取檔頭簽章（magic number）辨認真實格式，不依賴副檔名。分析全在本機完成，檔案不會上傳。

電子書轉 PDF

支援 MOBI、AZW3、EPUB、FB2、CBZ。在本機解析，檔案不會上傳。以瀏覽器列印引擎輸出，PDF 內為真文字（可選取、可搜尋），中文顯示正常。

⚠️ 設有 DRM 保護的檔案（例如在 Amazon 購買的 Kindle 電子書）無法開啟。這是加密限制，任何工具都無法處理。

檔案中轉站

手機上載，電腦下載（反之亦可）。檔案存放於你自己的 Cloudflare Worker，到期自動刪除。設定只保存在本機，不會傳送給任何第三方。

⚠️ 須先開設免費 Cloudflare 帳戶並部署 Worker，步驟見 worker/SETUP.md（毋須信用卡）。

Base64 編碼／解碼

支援中文（UTF-8）的 Base64 編碼與解碼。

URL 編碼／解碼

URL 百分比編碼與解碼。

亂碼修復

嘗試修復因編碼錯誤（Big5／GB／UTF-8）造成的中文亂碼。將文字按某編碼還原成位元組，再用正確編碼重新解讀。

Unicode 字符查詢

逐字顯示 Unicode 碼位、UTF-8 位元組、HTML 實體等資訊。

字頻分析
