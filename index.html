全形／半形轉換

標點格式化

統一引號樣式、修正省略號與破折號、清理標點前後空白。

拼音／粵拼

Markdown 預覽

即時預覽 Markdown，並可匯出 PDF 或複製 HTML。

CSV 表格

將 CSV 文字或檔案解析成表格，並可複製為 Markdown 表格。

JSON 格式化

格式化、壓縮、驗證 JSON。

中文數字

阿拉伯數字、中文數字、財務大寫互相轉換。

QR Code 生成

由任意文字或網址生成二維碼，可下載 PNG。

時區轉換

將一個時刻換算成多個時區，並顯示星期。

單位換算

長度、重量、溫度、面積換算，包括港式單位（斤、両、呎）。

短網址還原

嘗試將短網址還原成完整 URL。

⚠️ 純前端受瀏覽器 CORS 限制，部分短網址服務無法直接讀取。可選用公開 CORS 代理（需自行承擔風險）。

農曆／公曆換算

公曆與農曆互相換算，顯示星期、生肖、干支、節氣。

倉頡／速成查詢

輸入中文字，顯示每個字的倉頡碼組合（及速成碼）。

Base64 編碼／解碼

支援中文（UTF-8）的 Base64 編碼與解碼。

URL 編碼／解碼

URL 百分比編碼與解碼。

亂碼修復

嘗試修復因編碼錯誤（Big5／GB／UTF-8）造成的中文亂碼。將文字按某編碼還原成位元組，再用正確編碼重新解讀。

Unicode 字符查詢

逐字顯示 Unicode 碼位、UTF-8 位元組、HTML 實體等資訊。

字頻分析

統計文字中字元出現頻率，由高至低排序。
